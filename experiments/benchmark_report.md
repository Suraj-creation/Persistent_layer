# Synthetic Pipeline Demonstration — Not a Research Benchmark

## Data provenance

The checked-in result was generated by `EediDataLoader.create_sample_eedi_dataset()`, not by the Eedi platform or an external student dataset. It contains 48 generated rows from 12 synthetic learner IDs, four fraction items, and four hand-authored response archetypes. The text, correctness, and misconception labels are coupled by the generator.

The TF-IDF tier can therefore learn the generator's templates. The split by synthetic learner ID does not test generalization to independent response wording because each archetype reuses the same response templates across learners. Tier 3 processes held-out learner histories, but that also remains a simulation over those fixed archetypes.

Tier 1's zero misconception F1 is assigned by the benchmark code because the model has no misconception output; it is not a measured diagnostic comparison.
