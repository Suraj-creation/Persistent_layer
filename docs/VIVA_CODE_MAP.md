# Viva code map

**Language-Grounded Learner State Modeling**

Follow one explanation through the live assessment first. Start with a topic and study notes, answer the first question, open the learner inspector, and show how the resulting saved state influences the next question. Use the Training & retrieval workspace to explain the separate research capabilities after that walkthrough.

```text
Topic and notes → saved concept map and indexed references → first question
Learner explanation → raw receipt and NLP features → quoted rubric evidence
Accepted evidence → weighted concept update → committed topic snapshot
Committed snapshot → next diagnostic plan and retrieval → next question or report
```

Each code link opens the line for the method or calculation to show. The method names also work as search terms in an editor.

## Work one state update on the board

Take a new concept with alpha = 1 and beta = 1. A fresh 16-token response has confidence 0.8 and meets 3 of 4 criteria. Assume its category is partial.

| Quantity | Calculation | Result |
| --- | --- | --- |
| Rubric coverage | 3 ÷ 4 | 0.75 |
| Evidence weight | 0.8 × 1 for novelty × 1 for length | 0.8 |
| New alpha | 1 + 0.8 × 0.75 | 1.60 |
| New beta | 1 + 0.8 × 0.25 | 1.20 |
| Estimate | 1.60 ÷ (1.60 + 1.20) | 0.57143 |
| Uncertainty | Square root of `alpha × beta / ((alpha + beta)² × (alpha + beta + 1))` | 0.25386 |

An ambiguous answer, confidence below 0.55 or fewer than four tokens makes the numeric weight zero. A repeated response fingerprint receives 15% of the normal weight. A slip uses a 0.15 multiplier only on the missing-criterion beta increment. The estimate is a heuristic summary of accumulated evidence. The uncertainty is the standard deviation of that Beta distribution. Coaching changes neither number by itself. [Formula and quality gates](../packages/learner_state_core/assessment/state.py#L83), [Beta statistics](../packages/learner_state_core/assessment/state.py#L29).

Point to the fourth criterion after showing the calculation. It remains open in topic memory. A future repair can carry the exact skill into a new question and record which accepted answer addressed it. [Gap tracking](../packages/learner_state_core/assessment/state.py#L102), [next-question planning](../packages/learner_state_core/assessment/state.py#L202).
